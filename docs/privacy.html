Privacy Policy

Effective date: November 1, 2026

WordWise Korean ("the extension") is a free, open-source browser extension. This policy explains what data the extension does and does not handle.

Data Collection

The extension does not collect, transmit, or share any personal data. Specifically:

  • No browsing history is recorded or stored.
  • No page content is sent to any server.
  • No analytics or telemetry of any kind is gathered.
  • No third-party services or external APIs are contacted.

Local Processing Only

All annotation logic runs entirely on your device. The vocabulary database (6,064 TOPIK words) is bundled inside the extension package and never fetched from the internet.

User Settings

Your preferences (vocabulary level, translation language, font size, highlight toggle, website mode, and the domains you explicitly add) are saved using the browser's built-in chrome.storage.sync API. These settings may sync across your signed-in browser devices when browser sync is enabled. The domain list is a preference you manage, not a record of websites you visit. The current tab's URL is read when you open the popup to show website status and offer an add/remove shortcut; it is not stored unless you explicitly add its domain. The developer has no access to this data.

Permissions

  • storage — saves your preferences locally/synced.
  • activeTab — reads the current website when you open the extension popup, so you can add or remove its domain.
  • Host permissions (<all_urls>) — enables annotations on any Korean-language website you choose to visit.

The website mode controls where annotation processing runs; it does not change the browser's host permissions. In Only listed websites mode, unlisted pages are not scanned for Korean text or observed for text changes.

Remote Code

The extension does not load or execute any remote code. All JavaScript is bundled at build time and included in the extension package reviewed by the Chrome Web Store.

Children's Privacy

The extension does not collect any data from any user, including children under 13.

Changes to This Policy

If this policy changes, the updated version will be posted at this URL with a revised effective date.
